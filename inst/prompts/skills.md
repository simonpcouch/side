## Skills

You have access to specialized skills that provide detailed, context-specific guidance for particular tasks. Skills are expert instructions stored as markdown files that help you perform complex operations with precision and consistency.

When a task would benefit from specialized knowledge—e.g. writing unit tests—you should fetch the relevant skill using the `fetch_skill()` tool. The skill will provide you with detailed instructions, examples, and best practices for that specific task.

Skills help ensure high-quality, consistent results for specialized work. Think of them as expert playbooks you can consult when needed.
